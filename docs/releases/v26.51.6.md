# v26.51.6

### Added

- 新增基于 OreUI 的 LHolo 主菜单，支持投影管理、创建结构、结构变换、渲染设置、HUD 信息显示、快捷键、语言及实验性功能设置
- 材料清单新增原版物品图标，方便查看和辨认所需材料

### Changed

- 聊天命令 `LHolo` 与菜单快捷键统一打开新菜单，沿用已有快捷键配置，旧菜单不再提供打开入口
- 调整菜单布局、控件比例和设置项对齐，更新导航图标与切换动效；材料清单与主菜单使用一致的外框尺寸，列表保留独立滚动
- 菜单界面资源随模组内置，更新时随模组一起替换，无需单独覆盖游戏原版界面文件

### Fixed

- 修复快速连续修改结构变换、渲染及其他设置时，旧请求结果可能覆盖最新输入的问题
- 修复打开新菜单时，投影 HUD 和操作提示叠加遮挡界面的问题
