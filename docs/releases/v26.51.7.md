# v26.51.7

### Added

- 新增建造任务，支持在同一任务中管理多个投影文件，可分别调整位置、旋转、镜像、显隐与顺序，并保存每个文件的维度和绝对坐标
- 新增 HUD 布局编辑，可分别拖动投影 HUD 与材料 HUD，调整缩放和背景透明度，支持重置、取消和保存
- 缺失材料 HUD 新增原版物品图标、堆叠数量换算和分页显示；每页默认显示 5 项，可调整为 1～50 项，上一页与下一页快捷键默认不绑定

### Changed

- 投影 HUD 与材料 HUD 改用游戏原生字体和绘制，调整背景、间距与对齐；材料名称完整显示，数量靠右对齐，堆叠换算默认关闭
- HUD 设置分为投影与材料两个标签，快捷键按菜单、结构移动、分层显示和材料 HUD 分组，精简任务操作及快捷键文案，四种界面语言同步更新
- 配置文件按界面、渲染、HUD、输入和辅助放置分类整理，快捷键使用可读组合，清理不再使用的旧配置；旧配置自动迁移并保留备份，任务数据独立保存
- 优化互不重叠且不紧贴的多文件投影，减少移动文件时的重复合成；每个可见文件分别显示完整结构边框

### Fixed

- 修复多文件投影中部分区域缺块、纠错网格长时间不刷新的问题
- 修复任务文件的维度和绝对坐标保存问题，避免重新加载后位置偏移
- 修复修改文件路径后分层值可能超出新文件范围的问题，自动校正层数并保留原位置与变换；加载失败时保留原有效投影
- 恢复任务异步加载期间的“加载中...”提示，完成、失败或取消后自动清除
- 修复材料 HUD 中水图标显示为白色，以及床等物品颜色显示不正确的问题，保留旗帜颜色与图案
- 修复放大 HUD 后，方块物品图标出现三角形缺口的问题
- 修复 HUD 编辑时的界面切换与显示问题，避免编辑界面和菜单重叠
